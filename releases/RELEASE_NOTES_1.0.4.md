# Cunoku 1.0.4 — Android e iOS

## Android (recomendado)

1. Baixe **`Cunoku-1.0.4.apk`**
2. Instale por cima do app antigo (agora a assinatura é fixa — não precisa desinstalar)
3. Se a instalação falhar na **primeira** vez após esta correção, desinstale o app antigo uma vez e instale de novo; das próximas em diante atualiza normalmente

### Correção
- Assinatura Android **estável** (mesma keystore em todas as builds) — updates substituem a versão anterior

### Multiplayer
- **Bots / offline:** funciona no app
- **Wi‑Fi (LAN):** use o IP do host no app
- **Servidor online:** use a URL do servidor ao criar/entrar

## iOS

1. Baixe **`Cunoku-1.0.4.ipa`**
2. Assine e instale com Sideloadly, AltStore ou Xcode (conta Apple necessária)

## PC (opcional)

Node.js 20+: `npm ci --omit=dev` e `npm start` → `http://localhost:5000`

## Notas
- Versão do app: `1.0.4` (`com.cunoku.game`, versionCode 5)
