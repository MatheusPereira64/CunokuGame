# Cunoku 1.4.6

## Android

1. Quem está na 1.4.5 recebe esta versão pelo próprio app
2. Ou baixe **`Cunoku-1.4.6.apk`** e instale por cima da versão atual, sem desinstalar

### Novidades
- **Modo espectador:** digite o código de uma sala e toque em "Só assistir" para ver a partida sem ocupar vaga e sem ver as cartas escondidas
- **Perfil público:** cada conta do ranking tem uma página com posição, vitórias e conquistas; copie o link no seu perfil ou toque num jogador do ranking
- **Histórico de partidas:** as últimas 30 partidas ficam guardadas no aparelho, com placar e vencedor
- **Reconexão no assento:** se alguém cair, a mesa mostra a contagem e o jogador volta para o mesmo lugar, com as mesmas cartas
- **Convite para o Discord:** um botão na sala copia o link e o código já formatados para colar no canal
- **Estatísticas do jogo:** página com números anônimos (partidas por dia, modos, dificuldade, rodada do Cunoku), sem nome, conta ou IP de ninguém
- **Site:** abre sempre na versão mais nova e convida para baixar o app no Android ou no iPhone

### Ajustes
- Bot no fácil declara Cunoku mais cedo, por volta da rodada 9
- Teste automático que joga uma partida inteira antes de cada versão
- Código reorganizado para ficar mais fácil de manter
