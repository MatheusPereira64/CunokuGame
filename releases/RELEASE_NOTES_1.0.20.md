# Cunoku 1.0.20

## Android

1. Quem está na 1.0.19 recebe esta versão pelo próprio app
2. Ou baixe **`Cunoku-1.0.20.apk`** e instale por cima da versão atual, sem desinstalar

### Correções
- O aviso de nova versão não se perde mais quando a consulta ao GitHub falha: o app tenta de novo sozinho
- O app também procura atualização ao voltar do segundo plano
- Uma nova consulta não reabre o aviso nem interrompe uma atualização em andamento

## Notas
- Versão: `1.0.20` (`com.cunoku.game`, versionCode 21)
